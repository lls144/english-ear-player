# 原文语言校验（不改写原文）

- 2022 漫画例句保留全部人物插入语、while 对照结构和 attending it can be beneficial；未发现需要强制改写的明显语法错误。
- Modern society having entered ... 为独立主格结构；两个趋势与主题空位原样保留，不替用户填词。
- Folks are absorbed into a culture of ...：若原意是“沉浸于”，可另行考虑 absorbed in；into 更容易表示进入/融入一种文化。此处保留原句，不替换。
- the refreshing air：若意为“新鲜空气”，可选 fresh air；refreshing 强调令人清爽。保留原文，未改动音频用词。
- unfortunately 与 however 的语义不同，不能普遍互换。两个词都按原笔记保存于“原注辨析”，这条校验不冒充用户原注。
- Eventually、Consequently、In the long run 等表达的语义用途各异，保留原分类，不将其统称为可随意互换的高级结尾词。
- 斜线是原笔记的备选写法，MP3 使用短间隔分开其已有英文；模板是未完成结构，因此出现语法片段属于原文状态，不用新增句子掩盖。
