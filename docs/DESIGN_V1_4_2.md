# V1.4.2 continuous reading

The earlier frame fallback disabled ambient animations and lyric filters, while the playing class removed depth on pause. Chapter changes also combined a blanking text fade, two alternating background scenes and opaque/transparent dock changes. V1.4.2 separates these responsibilities.

One persistent blue/plum field runs two independent gradient paths lasting 22 and 27 seconds, including while paused. Negative phase offsets start with visible motion. It stops when the document is hidden or reduced motion is requested. Chapter mounts preserve that same field and replace a complete document fragment in one task, without fading the transcript to zero. The header keeps a distinct translucent frosted surface, a faint upper sheen and a long softened lower edge without a solid plateau. The dock retains a 12px frosted backdrop and translucent fill during lyric travel and slow-frame budgets. On wide tablet/desktop viewports its existing width is centered on the whole screen, bringing it left from the former reader-biased offset.

Sentence depth uses a symmetric bounded Gaussian of distance from the real current sentence. Pause keeps focus. A stationary pointer does not clear surrounding depth; a real drag, wheel or reading scroll does. Existing gesture/momentum states still defer recovery to an actual new cue. Only viewport-adjacent rows are filtered. Frame budgets reduce the row cascade and shadows while retaining the requested depth and continuous field. Contrast and reduced-motion accessibility preferences remain readable.

The native range remains the keyboard/accessibility control. Pointer coordinates, rather than a browser's thumb-only behavior, control its full 44px hit area. Pointer capture follows movement beyond its edges. Down/move only preview; up commits once; cancel, capture loss and window blur restore actual time. Native input/change events remain available for keyboard and assistive interaction. The audio element, sources, Media Session and MP3 bytes are unchanged.

Shared production/HTTPS browser cases measure computed depth while paused, actual animation progression, nonblank intermediate chapter frames, stable backdrop blur, native mobile touch taps away from the thumb, and captured/cancelled drags. Actual captures additionally compare background pixels over time. These are desktop browser automation results; physical iPhone/iPad/Android touch feel, rendering, lock screen and system interruptions remain unverified. Prior direct Windows WebKit network/EOF intermittence is retained as an environment limitation; explicit configured proxy use is recorded rather than calling a changed transport a code fix.
